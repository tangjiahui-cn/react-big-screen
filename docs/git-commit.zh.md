# Git 提交

简体中文 | [English](./git-commit.md)

提交信息中不得出现任何第三方 AI agent 的归属标识。

## 禁止的内容

包括但不限于：

- `Co-Authored-By:` trailer 指向 AI 工具（Claude、Copilot、Cursor 等）；
- `Generated with` / `Generated by` 等归属语句；
- 提交信息正文或 footer 中提及生成工具。

## 允许的例外

提交信息中因技术原因提及某工具名（如 `fix: handle claude code MCP timeout`），只要不是在声明归属。

## 执行方式

- 优先关闭 agent 自带的归属配置（如 Claude Code 的 `attribution.commit`、Copilot 的 `git.addAICoAuthor`），从源头不生成标识。
- 若无法关闭，用仓库级 `commit-msg` 钩子拦截并剥离匹配行。
- 匹配必须锚定归属语境（`Co-Authored-By:`、`Generated with`），不得只匹配工具名，以免误伤正常提交信息。

# Git commits

[简体中文](./git-commit.zh.md) | English

A commit message must not carry attribution to any third-party AI agent.

## Forbidden content

Including but not limited to:

- a `Co-Authored-By:` trailer pointing to an AI tool (Claude, Copilot, Cursor, …);
- attribution statements such as `Generated with` / `Generated by`;
- naming the generating tool in the commit body or footer.

## Allowed exception

Naming a tool for technical reasons is fine (e.g. `fix: handle claude code MCP timeout`), as long as the message is not claiming attribution.

## Enforcement

- Prefer disabling the agent's own attribution settings (e.g. Claude Code's `attribution.commit`, Copilot's `git.addAICoAuthor`) so the marker is never produced in the first place.
- If it cannot be disabled, intercept and strip the matching lines with a repository-level `commit-msg` hook.
- Matching must be anchored to attribution context (`Co-Authored-By:`, `Generated with`) and must never match the tool name alone, so that legitimate commit messages are not caught as collateral damage.
